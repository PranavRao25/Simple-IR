# Simple-IR
To build foundational components of a search engine, such as Sentence segmentation, Tokenization, etc and perform theoretical analysis

## Sentence Segmentation
naive, NLTK Punkt, and spaCy-based approaches

## Tokenization
top-down method, Penn Treebank tokenizer, and spaCy tokenizer

## Stemming and Lemmatization
Porter Stemmer and WordNet Lemmatizer

## Stopword Removal
curated list and corpus-specific data-driven approach
